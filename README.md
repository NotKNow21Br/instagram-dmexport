## ⚠️ IMPORTANT NOTICE: Violentmonkey Exclusive

> [!IMPORTANT]
> **This script is specifically optimized and strictly designed to run on [Violentmonkey](https://violentmonkey.github.io/)!**
>
> **Why Violentmonkey only?**
> - **Violentmonkey** handles the `GM_xmlhttpRequest` API with superior cross-origin reliability, which is essential to bypass CORS restrictions when fetching high-resolution photos, videos, and media hosted on Instagram/Facebook CDN servers (`cdninstagram.com`, `fbcdn.net`).
> - In alternative script managers (such as Tampermonkey), stricter security policies and context isolation frequently block bulk asynchronous media downloads or introduce severe throttling during ZIP and PDF generation.
> - **Use Violentmonkey to guarantee 100% stability and full feature availability.**

## 🚀 Installation Guide

### 1. Install the Violentmonkey browser extension:
- [Violentmonkey for Google Chrome](https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag)
- [Violentmonkey for Mozilla Firefox](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey/)
- [Violentmonkey for Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/violentmonkey/eeagobfjdenkkddmbclomhiblgggliao)
- *(Also fully compatible with Brave, Opera, and any Chromium-based browser).*

### 2. Install the Userscript:
1. Open the **Violentmonkey** extension dashboard.
2. Click the **`+`** (New Script) button.
3. Copy the entire contents of [`ig-dm-exporter.user.js`](./ig-dm-exporter.user.js).
4. Paste the code into the Violentmonkey editor and hit **Save & Close** (or press `Ctrl + S`).

## 💬 How to Use on Instagram

1. Go to [Instagram Web Direct](https://www.instagram.com/direct/) and log into your account.
2. Open the conversation thread you want to export.
3. Locate the top header of the chat and click the **download button with the Instagram gradient styling**.
4. In the export popup:
   - Verify the **`Pro by NotKNow21Br`** badge at the top.
   - Choose your output format (**HTML**, **PDF**, **TXT**, or **JSON**).
   - Toggle **Transcribe voice messages** and **Download media as .ZIP** if desired.
5. Click **"Export"** to start the download immediately!

*(You can also trigger it anytime by clicking the Violentmonkey browser icon and selecting **"📥 Open IG DM Exporter (by NotKNow21Br)"**).*
